# Parking lot

Ideas that came up during the build but are out of v1 scope. Not built, not scheduled.

- A "suggest where to place breakpoints" mode that scans a static request and recommends
  the best cache_control positions, instead of only checking positions you already chose.
- A short writeup on cache accounting (cache_creation vs cache_read vs input) that doubles
  as a teaching post, separate from this tool.
- Support for pasting a raw curl command or SDK call and extracting the JSON body
  automatically, instead of requiring the bare request body.
